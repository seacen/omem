## v1.0

The first public release. OMem ships with:

- Local-first ingest of **files, mail, calendar, and Loop** on macOS.
- A curated **Markdown wiki** as the source of truth, with four-level
  progressive disclosure.
- **Deterministic parsers** for Office formats, PDFs (digital + scanned),
  images (OCR + vision), email, and calendar.
- Built-in **`fts5`** search (BM25 + Chinese segmentation) and the optional
  **`qmd`** plugin for multi-path semantic + cross-language retrieval.
- **Skill** and **MCP** integrations so any agent can query your memory.
