## v1.0

首个公开版本。OMem 首发即包含：

- 在 macOS 上**本地优先**摄入 **文件、邮件、日历、Loop**。
- 一份经过整理的 **Markdown wiki** 作为真相来源，配四级渐进式披露。
- 对 Office 格式、PDF（数字版 + 扫描版）、图片（OCR + 视觉）、邮件、日历的**确定性 parser**。
- 内置 **`fts5`** 搜索（BM25 + 中文分词），以及可选的 **`qmd`** 插件，提供多路召回的语义 + 跨语言检索。
- **Skill** 与 **MCP** 集成，让任何 agent 都能查你的记忆。
