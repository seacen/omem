## 手动安装

<Steps>

1. **装这个二进制。** 一行命令:

   ```bash
   curl -fsSL https://github.com/seacen/omem/releases/latest/download/install.sh | sh
   ```

   它会把 `omem` 装到 `~/.local/bin/omem`——记得确认这个路径在你的 `PATH` 里。

2. **验一下它能跑:**

   ```bash
   omem version
   ```

   你应该能看到打印出一行版本号。到这儿,工具就算装好了。

3. **接着去 [setup](/zh-cn/getting-started/02-setup-wizard/)**,把你的数据接上、再挑一个 LLM。

</Steps>

<Aside type="note" title="不走 PyPI,不用 pip,也不用从源码编译">
OMem 发出来的,是一个编译好的二进制文件。你不用 `pip install`、不用 clone 仓库,也不用伺候什么 virtualenv——那行 curl 脚本下载一个可执行文件,整个安装就这么点事。以后升级,也走同一个脚本。
</Aside>

<details>
<summary>它为什么没签名,这对你意味着什么</summary>

macOS 上这个二进制**没有签名**(也就是没经过 Apple 公证)。不过那行 curl 脚本替你处理好了:它下载时就不带隔离(quarantine)标记,所以你不会撞上 Gatekeeper 那道"来自身份不明的开发者"的拦截。这是 v1.0 想清楚了才这么定的(对一个单人项目来说,代码签名的成本是实打实的),它一点不影响 OMem 怎么跑。万一你哪天用别的方式下载了这个二进制、又被 macOS 拦下,把隔离属性去掉就行:`xattr -dr com.apple.quarantine /path/to/omem`。

</details>
